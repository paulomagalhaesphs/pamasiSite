# Site PAMASI - Produtos Vô Geci

Site institucional da **PAMASI Atacado Produtos Alimentícios Ltda.**, empresa de atacado de alimentos que atua desde 1995 com a marca **Produtos Vô Geci**.

> 🚧 **Status:** em desenvolvimento

## 🎯 Objetivo

Apresentar a empresa e seus produtos na internet, facilitando o contato com clientes e parceiros.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Figma (protótipo do design)
